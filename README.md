## 🪙 Bitcoin Integration

LUXBIN uses **Bitcoin Core's proven Merkle tree algorithm** for energy verification.

**Based on:** [`bitcoin/src/consensus/merkle.cpp`](https://github.com/bitcoin/bitcoin/blob/master/src/consensus/merkle.cpp)

### Why Bitcoin's Algorithm?

- ✅ **16 years battle-tested** (2008-2024)
- ✅ **Billions of transactions** verified
- ✅ **Cryptographically proven** secure
- ✅ **Log(N) proof size** (efficient)
- ✅ **SHA-256 security** (tamper-proof)

### Energy as Transactions

```python
# Bitcoin
Transaction → Merkle Leaf → Merkle Root
Block Header = Proof of Transactions

# LUXBIN
Energy Engram → Merkle Leaf → Merkle Root
Energy Block = Proof of Energy Stored
```

**See:** [BITCOIN_ENERGY_MERKLE.md](BITCOIN_ENERGY_MERKLE.md) for full integration details
